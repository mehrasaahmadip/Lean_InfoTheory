Lean_InfoTheory

Shannon's channel capacity for discrete memoryless channels over finite alphabets, formalized in Lean 4 with Mathlib.

  • Blueprint The mathematics, chapter by chapter, with every statement linked to its Lean declaration. Also as a PDF.
  • Dependency graph Every definition and theorem as a node, colored by formalization status, with the edges recording what each result rests on.
  • Referee site One page per Lean declaration: statement, proof, and dependency graph, plus the Theorems, Claims, Sorries and Trust overviews.
  • API documentation Generated Lean documentation of the library and everything it imports.
  • Source on GitHub The Lean code, the blueprint sources, and the build configuration.
Main results: the capacity of the binary symmetric channel, Fano's inequality, and the converse of the channel coding theorem. The achievability half is stated but not yet proved.
